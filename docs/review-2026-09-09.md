## 一、需求满足

- [配置 API](../VideoNote.Server/Controllers/ProvidersController.cs) 和 [模型 API](../VideoNote.Server/Controllers/ModelsController.cs)：列表和详情仅返回 DTO；直接输入密钥加密保存；环境变量只保存名称、调用时解析；留空保留，显式清除。删除模型/提供商保留历史任务。
- [设置页面](../VideoNote.Client/Pages/Settings.razor)：提供商与模型两级 CRUD，独立表单组件、校验、空态和错误提示；界面采用简单 Bootstrap 布局，便于后续美化。
- [AI 工厂](../VideoNote.Server/AI/ChatClientFactory.cs)：官方 SDK 适配到 IChatClient；接受服务根地址或版本化地址。视频不以内联字节发送，后续视频理解管线须先经 Gemini File API 上传并使用文件引用。
- [媒体服务](../VideoNote.Server/Media/FfmpegService.cs)：默认 60 秒分段、5 秒重叠、1 fps 抽帧；WAV/MP3、文本软字幕提取；无字幕返回空结果，无音轨或不支持字幕类型给出明确错误。超时与取消会结束子进程。
- [上传存储](../VideoNote.Server/Storage/VideoFileStore.cs)：浏览器原生 File 请求体不经过 WASM 字节数组，服务端使用有界缓冲和逐块大小校验；临时文件完成后再落为正式文件；关联配置在上传过程中删除会返回冲突并清理视频。
- [模板管理](../VideoNote.Server/Controllers/PromptsController.cs)：迁移写入固定 ID 内置模板；复制后的模板可编辑；保存任务时冻结提示词内容，之后删除模板仅清空外键。

已确认的边界：验证任务页面只实现创建、查询、删除和配置选择，明确提示尚未执行分析；后台管线、报告、Agent 对话等仍属计划中。

## 二、审核发现与处理

| 等级 | 发现 | 已完成修复与验证 |

| 🟠 Important | 媒体重试失败会删除先前成功产物 | 写入独立临时产物，成功后替换；失败保留旧产物；失败抽帧清理本次操作目录 |
