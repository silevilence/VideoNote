# 前端界面重设计方案（开发中五项任务涉及界面）

日期：2026-09-16 · 状态：已经用户批准
范围：`VideoNote.Client` 呈现层 + `app.css`；功能逻辑、API、SignalR、upload.js 交互零变更。

## 目标

对 ROADMAP「开发中」五项任务涉及的前端界面，从用户使用视角重设计：新建任务页、任务列表、任务详情、Agent 对话区、设置页对话模型区、全局加载/空/错态。视觉上深化既有「放映室」暗色主题。

## 决策（用户确认）

1. 主题：深化现有暗色放映室主题（不换皮、不做双主题）。
2. 任务详情：双栏工作台——左报告/进度，右对话（sticky、钉底输入）；<1100px 堆叠。
3. 新建任务：分步向导形态 + 右侧「场记单」（任务单）实时摘要与校验清单。

## 约束（验收锚点，全部保留）

`tests/browser/pipeline.cjs` 依赖并逐字断言以下内容，重写不得破坏：

- id：`#video-file`、`#task-model`、`#task-prompt`、`#task-prompt-content`、`#conversation-question`、`#conversation-model`
- testid：`final-report`、`task-logs`、`conversation`、`conversation-stream`、`capability-warning`
- 角色/文案：`radio` + 直接理解/抽帧理解/字幕理解、「显示全部模型（手动覆盖）」、「上传并创建任务」、「发送问题」、「停止回复」、「重新加载历史」、「取消分析」、「删除任务」、「删除任务及物料」、「保存对话模型」
- 提示文案：`请选择分析模型。`、`当前模式没有匹配模型；`、`已删除任务「…」。`、`对话模型已保存。`、`对话历史加载失败，请重试。`、`模型或模板信息暂时加载失败，正在自动重试。`、`.kv-grid > div` 内「分析模型/暂不可用/test-model」
- 结构：`pre` 流式预览、`details`（open）分段摘要、`.conversation-message` 计数、加载失败时旧内容不残留（无 h1/无删除按钮）、390px 下侧栏收起且无横向滚动
- 页面加载后所有交互控件（模式卡、模型 select、提示词 textarea、提交按钮）必须可见可操作——因此向导不采用默认折叠，改为「三步分区 + 引导态」。

## 分界面设计

### 新建任务页
- 左列三个编号步骤分区（① 选片 ② 理解模式 ③ 模型与提示词），竖向引导线相连；满足条件的步骤编号变 ✓，第一个未满足步骤高亮为当前步。
- 右列 sticky「场记单」：视频/模式/模型/提示词实时摘要 + 校验清单（文件已选、扩展名、大小、模型已选、提示词 ≤16000）逐项 ✓/✗ + 提交按钮。
- 提交按钮保持可点击；点击后沿用现有顺序校验并内联报错，场记单同步标红缺失项（脚本依赖「未选模型点提交出现请选择分析模型。」路径）。
- 上传中：场记单内显示百分比 + 进度条 + 取消上传。

### 任务详情页
- 页头：文件名 + 状态/模式徽章 + 取消/返回/删除。
- 左主栏：分镜式阶段条（排队→预处理→理解→组合→完成）+ 进度条 + 阶段描述与耗时 → 解读报告（Markdown/流式 pre）→ 分段理解时间轴（details+pre）→ 分步日志 → 任务信息紧凑 kv（保持可见）→ 提示词快照。
- 右对话栏（sticky，420px）：聊天气泡（用户右/助手左）、消息区限高滚动、流式时自动贴底（用户上滚则不打扰）、空态可点击建议问题、输入区钉底；未完成任务显示锁定占位（不渲染 textarea）。

### 任务列表
- 行内：状态胶囊 + 文件名/模式徽章 + 阶段描述与细进度条（进行中）+ 右列耗时/创建时间。

### 设置页对话模型区
- 升级为带说明的设置节；锚点不变。
